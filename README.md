# Laptop Price Prediction

This project predicts laptop prices using machine learning based on laptop specifications.

## Features
- Data preprocessing
- Feature engineering
- Machine learning model for price prediction
- Python implementation

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn

## Dataset
The dataset contains laptop specifications such as:
- Brand
- RAM
- Storage
- CPU
- GPU
- Screen size
- Operating system

## Project Structure

laptop-price-prediction/
│
├── laptop_price.py
├── laptop_data.csv
└── README.md

## How to Run the Project

1. Download or clone this repository.

2. Put the project files in the same folder:
   - app.py
   - laptop_data.csv

3. Install dependencies:

pip install streamlit pandas numpy scikit-learn

4. Open Command Prompt (CMD) in the project folder.

5. Run the application:

streamlit run app.py
